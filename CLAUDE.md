# Open Higgsfield — VMNTe fork

Local studio over the Higgsfield API: image and video generation, trained
characters (Soul ID) and a local object library. Owner: Julio García Viamonte.
Fork `juliogv00/open-higgsfield` (branch `vmnte-personajes`), upstream
`wide-trace/open-higgsfield`. Spec: `~/specs/active/crear-personajes-open-higgsfield/SPEC.md`.

## Layout

This repository is `app/` inside a folder on Julio's Desktop:

```
Open Higgsfield/
  Open Higgsfield.app   launcher (generated by scripts/crear-lanzador.sh, not versioned)
  LEEME.md              Julio's map of the folder — keep it in sync with this file
  app/                  this repo
  datos/                user data: objetos/, personajes/ — never inside app/
  logs/                 servidor.log, eventos.log
```

`src/generation/paths.ts` finds `datos/` and `logs/` relative to the app, so the
whole folder can move. Run the server with `scripts/ohf.sh`, not bare `pnpm dev`:
it fixes Node 24, the port and the environment.

## Where things go

- **Model** → `src/generation/catalog/<model>.ts`, registered in `catalog/index.ts`.
  The shared mapper (`paths`) covers most; a custom body goes in `to-platform.ts`.
- **API call** → `src/generation/platform.ts`, exposed through `actions.ts` ("use server").
- **UI** → `src/openhiggsfield/`, styles in `openhiggsfield.css` using the `.ohf`
  tokens (dark studio, one lime accent for selection, primary action, liveness).
- **Stored data** → a folder under `datos/` via `paths.ts`, module in `src/generation/`.
- **API knowledge** → `docs/higgsfield-api.md`, with date and evidence.
- **Maintenance command** → a case in `scripts/ohf.sh`.

## Rules

- The API accepts unknown fields silently and charges anyway. Never ship a new
  field without one cheap real run proving it is honoured, and record the result
  in `docs/higgsfield-api.md`. Paid runs need Julio's explicit OK.
- The platform key comes from the macOS Keychain (`vmnte-higgsfield-id` /
  `-secret`, see `keychain.ts`). Never write it to a file.
- No spend tracking in the app: the API exposes no prices or balance; the
  dashboard is the source of truth. `logs/eventos.log` records calls without prices.
- UI copy is English (matches upstream); docs for Julio are Spanish.
- Match the surrounding code: comment density, naming, small modules.
- Done means `scripts/ohf.sh comprobar` passes and the change was tried in the app.
